# Security policy

## Reporting a vulnerability

Report a suspected vulnerability by email to <security@lexega.com>. Please do
not open a public issue or pull request for it.

Include a description of the problem, the steps that reproduce it and the
impact you expect.

Reports are acknowledged as quickly as we can manage; there is no formal
response time. Disclosure is coordinated: the details are published once a
fix is available.

The same contact is published at
<https://lexega.com/.well-known/security.txt>.
